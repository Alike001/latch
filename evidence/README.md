# Evidence vault

Preserve authentic proof as the project develops.

Planned evidence categories:
- provider
- telegraph-purchases
- failure-tests
- evaluation
- latency
- costs
- adoption
- screenshots
- demo

Every meaningful test should preserve timestamp, network, Intent, Provider, input, raw/normalized output, decision, cost, latency, and request/signal/transaction evidence where available.

Do not recreate or fabricate proof during submission week.
